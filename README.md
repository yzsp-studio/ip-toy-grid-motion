## 🇬🇧 English

Upload one IP character image and it first becomes a 9:16 black-background poster built from six irregular rounded panels, then extends into a 6-second vertical motion poster video. The motion follows a three-part timeline: panel 4 opens full screen for 0–2s, shrinks back into place at 2–3s while the other panels fly in, and the full six-panel layout animates subtly from 3–6s — sized for IP pitches and social display. Character identity, body coverage, props, background-colour logic and panel layout stay consistent across both stages, and prompts receive only the minimum necessary substitutions under an enforced fidelity ruleset rather than free rewriting. When a single pass is unstable it falls back to generating each panel separately and compositing them, or to a shorter stable 3–6 second motion.

### ✨ What it does

- One IP character image in → 9:16 black-background irregular rounded six-panel toy poster out
- That same poster in → a 6-second vertical six-panel motion poster video out
- Three-part timeline: panel 4 full-screen open → shrink back and fly in → stable subtle motion
- Locks character identity, body coverage, props and background-colour logic
- Prompt fidelity: minimum necessary substitutions, no free rewriting of the template
- Fallback to per-panel generation and compositing, or a shorter stable motion, when one pass fails
